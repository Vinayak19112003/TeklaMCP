METHOD 1: PUSH WITH PERSONAL ACCESS TOKEN (Recommended)
=================================================================

Step 1: Create Personal Access Token
────────────────────────────────────
1. Go to: https://github.com/settings/tokens
2. Click: "Generate new token (classic)"
3. Name: InstantEstimate Upload
4. Select scope: ✅ repo (full control of repositories)
5. Click: "Generate token"
6. ⚠️  COPY THE TOKEN - you won't see it again!

Step 2: Push to GitHub
──────────────────────
cd /home/user/instant-estimate

git push https://YOUR_TOKEN@github.com/Vinayak19112003/InstantEstimate.git main

Replace YOUR_TOKEN with the token you copied.

Example:
git push https://ghp_xxxxxxxxxxxxxxxxxxxx@github.com/Vinayak19112003/InstantEstimate.git main
